# AI-ревьюер автотестов

AI-ревьюер проверяет изменённые Playwright-тесты после зелёных lint и test. Он читает `CODEX.md`, `REVIEW.md` и diff Pull Request, затем создаёт или обновляет один комментарий в PR.

Замечания модели носят рекомендательный характер. Ошибки lint и тестов блокируют CI, а найденные AI-ревьюером проблемы должен подтвердить человек.

## Настройка GitHub

1. Откройте `Settings → Secrets and variables → Actions`.
2. Создайте repository secret `POLZA_AI_API_KEY`.
3. Убедитесь, что GitHub Actions разрешено создавать комментарии в Pull Request.
4. Смержите workflow в `main`: GitHub запускает только доверенную версию reviewer из целевой ветки.
5. Откройте PR в `main`.

Workflow запускается через `workflow_run` только после успешного `Playwright CI`. Этот тип события имеет доступ к секретам, поэтому код из PR не загружается и не запускается: reviewer берётся из `main`, а diff читается через GitHub API как недоверенный текст. Нельзя заменять `ref: main` на ветку автора PR или выполнять команды из проверяемого кода.

## Локальный запуск

Передайте ключ через окружение и укажите базовую ветку или коммит:

```bash
POLZA_AI_API_KEY=... npm run review:ai -- --base origin/main
```

Локальный запуск использует `--dry-run`: результат печатается в терминал, комментарий в GitHub не создаётся.

В workflow используется модель `qwen/qwen3.8-flash`. Локальный скрипт позволяет заменить модель через `POLZA_AI_MODEL`:

```bash
POLZA_AI_MODEL=z-ai/glm-5.3-flash POLZA_AI_API_KEY=... npm run review:ai -- --base origin/main
```

Адрес API по умолчанию — `https://polza.ai/api/v1`. Для тестового сервера его можно заменить через `POLZA_AI_BASE_URL`.

## Ограничения стоимости и контекста

- На проверку отправляются только patch для `tests/`, `playwright.config.ts` и `eslint.config.mjs`.
- Максимальный diff — 50 000 символов. Большой PR нужно разделить.
- Ответ ограничен 1 600 токенами.
- Таймаут запроса по умолчанию — 120 секунд; меняется через `AI_REVIEW_TIMEOUT_MS`.
- Повторный запуск обновляет прежний комментарий бота и не создаёт цепочку дублей.
